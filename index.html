Course terms in this project

Course termIn this project
Measurement systemHC-SR04 (sensing) → timer (conversion) → ESP32 (processing) → LCD / Wi-Fi (display, transmission)
Static calibrationCompare the sensor with a known reference (the stepper rail) at many points
Input / outputInput I = true distance · Output O = sensor reading
Sensitivity (K) and bias (a)Slope and offset of the line O = K·I + a
LinearityHow close the readings are to that straight line
HysteresisDifferent readings going up and coming back down
Accuracy / inaccuracyLargest error vs the true distance, in % of full scale
RepeatabilityHow much repeated readings at one point scatter (σ)
ResolutionSmallest change the system can show or set (the rail: 2.5 µm)
Environmental inputAir temperature changes the speed of sound, so it is compensated with the DHT22

Demo mode works offline · Live mode needs internet and the station password.
